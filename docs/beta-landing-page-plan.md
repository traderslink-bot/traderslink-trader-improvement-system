# Beta Landing Page Plan

## Goal

Create the public share link `traderslink.pro/beta` for the free Discord beta.
It explains the available tools before a visitor chooses to continue with
Discord. It is not hosted on the private dashboard domain.

## Approved design

- Full-page soft light-blue background.
- A larger white frame centered on desktop with a clearly visible lifted
  shadow, containing the existing dark-blue Beta App card.
- Reuse the Press Release beta promotion's dark-blue stacked tool-card concept.
- One action at the end: **Continue with Discord**.
- The action begins login at `app.traderslink.pro`, which leads to the one-time
  Welcome choice and then Workspace.

## Boundaries

- Do not alter the public homepage or the dashboard host root behavior.
- Do not change Discord OAuth, newsletter consent, account data, or Academy
  progress in this slice.
- Production deployment remains a separate owner-authorized action.
