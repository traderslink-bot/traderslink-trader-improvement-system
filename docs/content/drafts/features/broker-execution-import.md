# Broker Execution Import for Trade Review

Broker execution import helps traders review what actually happened in a trade instead of relying only on memory or manual notes. Trader Intelligence is being built to support broker execution imports so active traders can turn entries, exits, adds, reductions, and trade timing into structured review data.

For active traders, especially day traders and small-cap traders, this matters because one trade can include several executions. A manual journal may miss important details. Imported executions can make the review process more accurate.

## What This Feature Reviews

Broker execution import is designed to bring trade activity into Trader Intelligence so it can be reviewed in a more organized way.

Execution data can help show:

- When the trader entered.
- Where the trader added size.
- Where the trader reduced size.
- When partial exits happened.
- When the final exit happened.
- How long the position was held.
- Whether the trader re-entered.
- How execution behavior affected the trade review.

The goal is to create a better foundation for analysis than a trader trying to rebuild the trade from memory.

## Why It Matters For Trade Review

A trading journal is only as good as the information inside it.

Manual notes are useful, but they can be incomplete. After a fast session, it is easy to forget the exact order of executions, the size of each add, or where the trade started to change. Broker execution import helps preserve the factual sequence.

That factual sequence can support better review questions:

- Did the trader add after confirmation or after weakness appeared?
- Did the trader reduce size when the trade stopped working?
- Did the trader take several unnecessary re-entries?
- Did the trader exit early or late compared with the trade idea?
- Did the trade become worse after a specific execution?

## How Trader Intelligence Uses This Information

Trader Intelligence is being built around execution-based review. Broker execution import is part of that foundation.

The planned workflow is to import broker data, organize the executions into trades, and use that information to support review of entries, exits, scaling, trade management, session timing, and repeated mistakes.

When market context is available, imported executions can also support review around support, resistance, and price movement after the trade.

This is not financial advice. It is a review workflow that helps traders study their own decisions.

## Example Review Questions

Broker execution import can help traders review questions like:

- Was my first entry close to the area I planned?
- Did my average price get worse because I added too late?
- Did I reduce into strength or panic sell into weakness?
- Did my re-entry improve the trade or create another mistake?
- Did I trade differently at the market open than later in the day?
- Did my largest loss come from the entry, the add, or the failure to exit?

These questions are difficult to answer clearly without accurate execution data.

## Common Mistakes This Can Help Surface

Imported executions can help expose patterns such as:

- Adding to a losing trade repeatedly.
- Taking partial exits too quickly.
- Re-entering without a clear reason.
- Increasing size after the best setup has passed.
- Holding a failed trade longer than planned.
- Trading more aggressively after a loss.

The purpose is not to blame the trader. The purpose is to make behavior easier to review.

## FAQ

### What is broker execution import?

Broker execution import means bringing trade execution data from a broker into a trading journal or trade review tool. This can include entries, exits, partial fills, adds, reductions, quantity, price, and time.

### Why is broker execution import useful for a trading journal?

It helps make the journal more accurate. Instead of manually typing every trade detail, traders can review the actual execution sequence and study how the trade was managed.

### Will Trader Intelligence support broker execution imports?

Broker execution import is a planned part of Trader Intelligence. The goal is to support structured review from actual execution data.

### Is CSV import the same as direct broker sync?

Not always. CSV import usually means uploading exported broker trade data. Direct broker sync usually means connecting to a broker or data source. Trader Intelligence should describe only the supported import methods once the product details are finalized.

### Can broker execution import help track mistakes?

Yes, imported execution data can help reveal repeated behavior such as late entries, poor exits, adverse adds, and re-entry problems. The trader still needs to review the context.

### Does importing executions provide financial advice?

No. Importing executions supports trade review. It does not provide financial advice or tell a trader what to buy or sell.
