# Order Book

An order book shows buy and sell interest at different price levels. Traders review the order book to understand bid depth, ask depth, spread, liquidity, and possible execution conditions.

The order book does not guarantee future price movement. Orders can appear, disappear, change size, or be cancelled quickly.

## Simple Definition

An order book displays current buy and sell orders by price level.

It may show:

1. Bid prices.
2. Ask prices.
3. Bid size.
4. Ask size.
5. Spread.
6. Market depth.
7. Liquidity at different levels.
8. Order flow changes.

The visible order book is only part of market activity, but it can help traders understand execution context.

## Why The Order Book Matters

The order book matters because it can show where liquidity appears to be available.

This is where traders can get into trouble. They may assume a large bid or ask is permanent, but displayed size can change quickly.

A useful review asks:

1. What did the bid and ask look like?
2. Was the spread wide?
3. Was there enough liquidity?
4. Did visible size disappear?
5. Did the trader get slippage?
6. Did the order book support the trade plan?

The order book should support execution review, not replace risk management.

## Example

A stock shows a bid at $2.00 and an ask at $2.05. There may be several bid and ask levels above and below those prices.

If bid size is thin and the spread is wide, a trader may need to be more careful with order type and position size.

## How To Review Order Book Behavior

A good order book review looks at liquidity and execution quality.

Useful questions include:

1. Was there enough depth for the trade size?
2. Did spread widen during the trade?
3. Did the bid support price?
4. Did the ask lift quickly?
5. Did the trader chase visible liquidity?
6. Did the order book help or hurt execution?

The goal is to understand whether order book conditions affected the trade.

## FAQ

### What is an order book?

An order book is a display of current buy and sell interest at different price levels.

### Is the order book the same as Level 2?

They are closely related. Level 2 often displays order book depth by price and market participant.

### Does the order book predict price?

No. The order book can change quickly and does not guarantee future price movement.

### Why do traders watch the order book?

They watch it to understand liquidity, bid and ask depth, spread, and possible execution risk.

### Can order book size be misleading?

Yes. Displayed orders can be cancelled, moved, hidden, or changed quickly.
