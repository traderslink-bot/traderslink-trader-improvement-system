## Writing Rules To Preserve

All generated content should remain markdown only.

Do not write:

- JSX
- HTML
- CSS
- React components
- Next.js pages
- Production route files
- Production schema files
- Components

Every draft should include YAML frontmatter and follow:

```text
docs/content/seo-writing-system-prompt.md
```

Every draft should be checked against:

```text
docs/content/seo-quality-checklist.md
```

## Voice Direction

The content should not sound too robotic or overly AI-generated.

Use plain English and grounded trader phrasing. The content should feel like practical trader education, not generic encyclopedia copy.

Good tone examples:

- "This is where traders can get into trouble."
- "The headline is only the start."
- "The chart can look exciting, but the filing details still matter."
- "This is not about predicting the move. It is about understanding the risk."
- "That sounds simple, but it matters."

Do not overdo personality. Keep it useful, practical, and professional.

## Compliance And Safety Guardrails

Continue avoiding:

- Financial advice
- Buy or sell signals
- Profit promises
- Claims that a chart pattern guarantees a move
- Claims that a filing guarantees dilution or a price move
- Claims that a press release guarantees a stock will run
- Claims that catalysts, FDA updates, or clinical trial news guarantee price movement
- Claims that Trader Intelligence guarantees better results
- Claims that Trader Intelligence tells users what to trade

Use careful language:

- helps review
- helps organize
- helps analyze
- can help surface
- may indicate
- traders often watch
- context matters
- educational only
- not financial advice
